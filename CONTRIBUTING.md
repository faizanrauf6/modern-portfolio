# Contributing

This is Muhammad Faizan Rauf's personal portfolio, adapted from an MIT-licensed portfolio template.

Use `npm ci` and `npm run dev` to start locally. Content lives in `data/portfolio.json`; shared UI lives in `components/`, and routes live in `app/`.

Keep professional claims grounded in the CV or other supplied evidence. Leave unknown links and statistics unset. Preserve the original MIT notice and the attribution on existing educational articles.

Before submitting changes, run `npm run lint`, `npx tsc --noEmit`, `npm run build`, and `npm test`. Browser tests require Playwright Chromium.
